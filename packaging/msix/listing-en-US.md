## Description

Ascolotl is a focused editor for AsciiDoc and Markdown documents. Write the source on the left and see the page on the right, or edit the rendered page directly, then export it to PDF, HTML, EPUB or DocBook. Everything runs on your computer: no browser engine, no Ruby, no Java, no account and no cloud.

Four views, one document
Read the page undisturbed, edit it in place (WYSIWYG), work with source and live preview side by side (Split), or write the source alone. Ctrl+1 to Ctrl+4 switch between them, and each tab keeps its own view. Click a rendered block to edit it in place; the source text always stays the single source of truth.

Write faster
A formatting toolbar and a right-click menu for bold, italic, code, links, headings, lists, quotes, code blocks, images and tables. Completion for macros, attributes, link targets and code languages, a searchable syntax reference (F1) and a command palette (Ctrl+Shift+P) that reaches every command by name. Lists, quotes and code fences continue on Enter.

Tables made easy
Insert, delete, move and sort rows and columns from the toolbar or a right-click, in the source or on the page; merge and split AsciiDoc cells.

Spell checking
Misspelled words are underlined in the source and on the page, with suggestions, Add to dictionary and Ignore. English, French, German, Italian and Spanish dictionaries are included.

Math and diagrams
Formulas (LaTeX and AsciiMath) are typeset offline in the preview and every export. Mermaid, PlantUML and Graphviz diagrams can be drawn with tools installed on your computer or with a Kroki service.

Export and styles
Export to PDF (portrait or landscape), accessible tagged PDF/UA, HTML, EPUB, DocBook XML or a linked static website of a whole folder. Load an asciidoctor-pdf theme once and it styles every export and the live preview, title page included. Page Preview shows the document as the exported PDF's pages.

Copy and paste
Copy blocks or a selection from the page and paste them, formatted, into Teams, Outlook, Word or a GitHub comment. Paste a screenshot and it is saved as a PNG beside your document and inserted.

Made for long sessions
Tabs, project folders with a file tree, an outline panel, session restore and crash recovery. Light, dark or system theme. Every feature works from the keyboard, and screen readers can read the menus, dialogs and the page. The interface is in English, French, German, Italian or Spanish.

Import Word (.docx), Markdown, HTML, PDF and plain text documents as AsciiDoc.
